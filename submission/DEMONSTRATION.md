# Demonstration storyboard and recording gate

The Project Demonstration format has NOT been verified. The supplied addendum suggests a 30-second video or up to seven English slides as a fallback; this is not confirmed acceptance. A three-minute pitch is separate. Official resources and challenge URLs returned HTTP errors during this session. Team Owner must inspect the current Project tab/linked guide and São Paulo instructions.

Record the actual app only after the real-data gate passes. Use silent English captions, no people or third-party audio. No screen recording exists yet.

| Time | Screen and English caption |
|---|---|
| 0–5 s | Open Pantanal map. “More hotspots—or a more sensitive sensor?” |
| 5–13 s | Select a verified complete month. Show observed cell-days and prior same-month median only if supported. Caption names exact month, sensor and baseline years. |
| 13–23 s | Compare native detections and common grid. Show actual holdout MAE and bias if evaluated; otherwise state calibration unavailable and why. |
| 23–30 s | Download selected observations. Show CSV fields, NASA provenance and Ember Atlas. |

For a separate three-minute pitch: 30 s problem/audience, 60 s actual workflow, 45 s method and measured evidence, 30 s limits, 15 s pilot hypothesis. Never fill missing results with invented numbers. Upload the screen recording to an authorized public media host; test anonymously, measure runtime and review every frame before supplying its URL to the portal.
